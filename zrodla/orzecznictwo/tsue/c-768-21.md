# C-768/21 TR / Land Hessen (2024-09-26)

**ECLI:EU:C:2024:785** · TSUE, pierwsza izba

## Teza (streszczenie sentencji – sygnalizacyjnie)

Po stwierdzeniu naruszenia organ nadzorczy nie musi stosować środka naprawczego (w tym kary), jeżeli nie jest to odpowiednie, niezbędne lub proporcjonalne do usunięcia uchybienia (np. administrator sam już podjął działania).
