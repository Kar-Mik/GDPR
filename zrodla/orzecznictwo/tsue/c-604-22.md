# C-604/22 IAB Europe (2024-03-07)

## Teza

Ciąg TC String zapisujący preferencje użytkownika jest daną osobową, jeśli można go powiązać z identyfikatorem (np. adresem IP). Organizacja ustalająca ramy (TCF) może być współadministratorem bez bezpośredniego dostępu do danych.

- kluczowe punkty uzasadnienia (numery pkt)
- dalsze orzecznictwo, które powołuje wyrok
