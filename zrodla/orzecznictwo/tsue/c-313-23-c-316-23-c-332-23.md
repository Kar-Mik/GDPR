# C-313/23, C-316/23, C-332/23 Inspektorat kam Visshia sadeben savet (2025-04-30)

**ECLI:EU:C:2025:303** · TSUE, pierwsza izba

## Teza (streszczenie sentencji – sygnalizacyjnie)

Ujawnienie organowi sądowemu danych objętych tajemnicą bankową (sędziowie i ich rodziny) w celu weryfikacji oświadczeń majątkowych to przetwarzanie objęte RODO. Sąd wydający zezwolenie na ujawnienie nie jest administratorem ani organem nadzorczym (art. 51) i nie musi z urzędu badać bezpieczeństwa danych, gdy nie wniesiono środka z art. 79.
