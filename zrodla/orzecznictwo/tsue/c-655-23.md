# C-655/23 IP / Quirin Privatbank (2025-09-04)

**ECLI:EU:C:2025:655** · TSUE, czwarta izba

## Teza (streszczenie sentencji – sygnalizacyjnie)

RODO nie daje roszczenia o zaniechanie przyszłych naruszeń (gdy osoba nie żąda usunięcia), ale prawo krajowe może je przewidzieć. Obawa i niezadowolenie po nieuprawnionym przekazaniu danych mogą być szkodą niemajątkową, jeśli zostaną wykazane wraz z negatywnymi skutkami. Stopień winy administratora ani uzyskany nakaz zaniechania nie obniżają odszkodowania.
